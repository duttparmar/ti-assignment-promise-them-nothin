# Session exports

This assignment scores the raw AI session, not a recap.

**Do this before opening the PR:**

1. In Cursor, open this chat → **Export Chat**.
2. Save the file here as `01-implementation.md` (full prompts, tool calls, diffs, errors).
3. Do not edit it down to highlights.

If Export Chat is unavailable, copy the conversation’s `.jsonl` from Cursor’s `agent-transcripts` folder into this directory instead. Summaries are not a substitute.
